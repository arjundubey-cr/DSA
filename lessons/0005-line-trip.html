Line Trip

The answer is the longest stretch between refuels. Watch out for the stretch that gets doubled.

The Problem

A road runs from point 0 to point x. You drive 0 → x → 0, burning 1 liter per unit. You start with a full tank. Gas stations sit at a₁ < a₂ < … < aₙ, and each one refills you to full. There are no stations at 0 or at x. Find the minimum tank size that gets you home. (CF 1901A; 1 ≤ t ≤ 1000, 1 ≤ n ≤ 50, 2 ≤ x ≤ 100.)

x = 7, stations at 1, 2, 5. Each bar is one stretch between refuels. The red one is the bottleneck.

The Idea: Bottleneck = Max Stretch

You refuel at every station, so no decision is ever made. The tank only has to survive the longest single stretch between two fill-ups. This is the simplest form of greedy: the global answer is a max over local pieces (USACO Guide: Greedy).

List every stretch:

  1. 0 → a₁: length a₁. The full starting tank works like a station at 0.
  2. aᵢ₋₁ → aᵢ: the gaps between neighboring stations.
  3. aₙ → x → aₙ: length 2·(x − aₙ). There's nowhere to refuel at x.

The return trip covers the same gaps in reverse, so it adds nothing new.

The one trick: stretch 3 is the only one that's doubled. Forget the 2 and you fail the very first example (you'd print 3 instead of 4).

Complexity

Time: O(n) per test Space: O(1) extra

import sys
input = sys.stdin.readline

for _ in range(int(input())):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    ans = max(a[0], 2 * (x - a[-1]))
    for i in range(1, n):
        ans = max(ans, a[i] - a[i - 1])
    print(ans)

Pattern Connections

  • Max-gap / bottleneck: "smallest capacity that survives every segment" usually means max over segments. See greedy patterns reference.
  • When it breaks: if stations had limited fuel, the check "does capacity V work?" would need a simulation. Feasibility only gets easier as V grows, so you'd binary-search on V. That's binary search on the answer, which comes up later in NC150 (Koko Eating Bananas).
