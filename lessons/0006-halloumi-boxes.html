Lesson 0006 · Ad hoc observation · Codeforces 1903A

Halloumi Boxes

Ask what the operation can do at its smallest. A length-2 reversal is a swap, and swaps can sort anything.

The Problem

You're given n boxes with numbers a₁…aₙ. One operation reverses any subarray of length at most k. Can you sort the boxes in non-decreasing order? Print YES or NO. (CF 1903A; 1 ≤ t ≤ 100, 1 ≤ k ≤ n ≤ 100, aᵢ ≤ 10⁹.)

The Idea: Shrink the Operation

Don't think about long reversals. Ask what the smallest useful operation is:

  • Length 1: reversing one element changes nothing.
  • Length 2: reversing [p, q] gives [q, p]. That's an adjacent swap.

Bubble sort uses nothing except adjacent swaps, and it sorts any array (Wikipedia: Bubble sort). So:

k ≥ 2 → always YES.   k = 1 → YES only if it's already sorted.

This is an ad hoc problem. There's no named algorithm, just one observation, found by trying tiny cases (USACO Guide: Ad Hoc). Div 2 A problems are often like this.

Complexity

Time: O(n log n) with a == sorted(a) or O(n) with a pairwise check

With n ≤ 100, both are fine. Write whichever you can't get wrong.

Feel It: Sort Using Only Short Reversals

Click a start box, then an end box. That segment reverses if its length ≤ k. Try k = 2 first. Then switch to k = 1 and see that nothing moves.

k = 2

import sys
input = sys.stdin.readline

for _ in range(int(input())):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print("YES" if k > 1 or a == sorted(a) else "NO")

Pattern Connections

  • "Shrink the operation": when a problem offers a big operation, find the smallest version of it. If that's an adjacent swap, every ordering is reachable. See ad hoc observations reference.
  • Line Trip (0005): also a one-line answer once you see the observation. That's typical of Div 2 A.
  • Harder versions: if only reversals of length exactly k were allowed, the answer changes. That's a good question for your teacher.

Primary Source

USACO Guide: Ad Hoc Problems. It covers how to find observations: draw small cases and write down what you notice. Read it once and you'll recognize the shape of most Div 2 A problems.
