How to hunt for the observation

  • Try tiny cases by hand: n = 1, 2, 3
  • Shrink the operation to its smallest non-trivial form
  • Ask what never changes (an invariant) and what can change (what's reachable)

Adjacent swap ⇒ any permutation

Recognize
  • "Can you sort / reach any order using operation X?"
  • If X can produce an adjacent swap, the answer is always YES (bubble sort)
  • If X is a no-op, the array must already be in the target order

Trap: "at most k" vs "exactly k" are different problems. With exactly k, length 2 isn't available.

Halloumi Boxes (CF 1903A)
print("YES" if k > 1 or a == sorted(a) else "NO")

O(n log n) · lesson 0006

Sorted checks in Python

a == sorted(a)                                   # O(n log n), can't get wrong
all(a[i] <= a[i+1] for i in range(len(a) - 1))  # O(n), non-decreasing

Non-decreasing allows equal neighbors: use <=, not <.
