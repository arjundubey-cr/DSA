Max-gap / Bottleneck

Recognize
  • "Minimum capacity / size / range so that every segment fits"
  • Forced refill or reset at known points, so no choices are made
  • Answer = max over segments

Trap: segments with no reset at the far end count twice (out and back).

Line Trip (CF 1901A)
ans = max(a[0], 2 * (x - a[-1]))
for i in range(1, n):
    ans = max(ans, a[i] - a[i-1])

O(n) time · O(1) space · lesson 0005

When greedy stops working

  • Resources are limited (station fuel, costs) → "does V work?" needs a simulation → binary search on V if feasibility is monotonic
  • Choices interact (take/skip affects later options) → probably DP
  • Greedy needs a proof: an exchange argument, or "no choice exists" like the case above
